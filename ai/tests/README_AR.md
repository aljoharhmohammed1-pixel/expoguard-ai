# الاختبارات الآلية

من مجلد expo_modle، شغّل المجموعة السريعة:

```powershell
.\ai\.venv\Scripts\python.exe -m ai.run_tests --report ai/tests/reports/fast.json
```

تُكتشف 90 حالة: تُشغّل 88 دون تحميل الأوزان، ويُتجاوز اختبارا التكامل الحقيقي بوضوح. لا يُعتبر التجاوز إثباتًا لنجاح التكامل.

لتشغيل المجموعة كاملة بالأوزان المحلية:

```powershell
.\ai\.venv\Scripts\python.exe -m ai.run_tests --integration --report ai/tests/reports/integration.json
```

النتيجة: رمز خروج 0 عند النجاح و1 عند الفشل. التقرير يحتوي عدد الحالات والتجاوزات والأخطاء والإخفاقات والزمن وتاريخ التنفيذ. ملفات التقارير تُستبدل عند إعادة التشغيل إلى المسار نفسه. لا يلزم pytest؛ المجموعة مبنية على unittest، مع Pydantic وPillow من بيئة المشروع. التكامل الحقيقي يحتاج Ultralytics واعتمادياته والأوزان والعينات المحلية؛ غيابها عند طلب --integration يُفشل الاختبار بدل تجاوزه بصمت. لا تحتوي هذه الاختبارات تنزيل بيانات أو تدريبًا.

| المجموعة | ما تتحقق منه |
|---|---|
| test_contract.py | الحقول والأنواع والثقة والصناديق واتساق الحالات والمراجع ومطابقة الطلب ومنع ALARM ومطابقة JSON Schema للشيفرة |
| test_evaluation.py | صحة مقاييس التقييم والمراجعة البشرية وحالات الامتناع وتوليد تقرير قابل للمراجعة |
| test_multimodal.py | عقد v2، النص العربي وإزاحات أدلته وUTF-8، وواجهات الصور والصوت ببدائل مزوّدين محلية، والفشل دون نتائج جزئية |
| test_operations.py | استقلال درجة الربط عن الثقة، وتعارض الموقع والزمن، والأدلة المعتمدة وصلاحيتها ومصادر الإجراءات، وعدم اعتماد تقرير اختبار قديم |
| test_analysis.py وtest_fire_adapter.py | تحويل الأدلة والمرشحات والتجميع والاتجاه والمعرّفات وتحميل النموذج مرة واحدة وإعدادات الكشف |
| test_quality_errors.py | الصور التالفة والمظلمة والشفافية والصيغ والحجم والإحداثيات وفشل الاستدلال والتعافي |
| test_cli.py | ملفات المدخلات حتى JSON الناتج، مع محلل حقيقي ونموذج بديل للاختبار؛ رموز الخروج 0/1/2 |
| test_legacy.py | الصيغة القديمة وترتيب FIRE/SMOKE وتقريب الثقة وتوقيت الرياض والقيم الافتراضية القديمة والإلحاق بـJSONL وخيارات التشغيل |
| test_real_integration.py | المسار القديم في عملية مستقلة بالأوزان الحقيقية؛ الصور الست في المسار الجديد ومقارنة الفئات والثقة والصناديق والتحقق من ثبات بصمة الأوزان |

اختبارات التوافق تُثبت السلوك السابق الموجود، بما فيه الموقع الافتراضي، ولا توصي باستخدام هذه القيم في التكامل الجديد. لم تتغير شيفرة المسار القديم من أجل هذه الاختبارات.

سماحية مقارنة الثقة والإحداثيات المطبعة بالتقرير السابق 0.0001. تغيّر إصدار مكتبات الاستدلال أو العتاد قد يسبب فروقًا تستحق التحقيق؛ لا تُحدّث النتائج المرجعية تلقائيًا لتمرير الاختبار.

شغّل هذا المجلد فقط عند اكتشاف الاختبارات. سكربتات inference/test_fire_smoke_samples.py وinference/test_surveillance_video.py هي عروض قد تنزّل ملفات وتكتب مخرجات، وليست ضمن المجموعة السريعة.

هذه اختبارات تكامل محلية وعدم تراجع؛ لا تختبر خادمًا فعليًا أو تقيس دقة ميدانية مستقلة. الست صور مرجع صغير سابق وليست ضمانًا لسلامة كل مشهد. سيناريوهات بث الكاميرات الطويلة والحمل المتزامن وتكامل الخادم تحتاج اختبارات منفصلة لاحقًا.

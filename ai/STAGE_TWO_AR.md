# المرحلة الثانية: الصور العامة والنص العربي والصوت

حالة التنفيذ: مسارات التحليل وعقود البيانات وواجهات ربط المزوّدين جاهزة ومختبرة محليًا. بناءً على اختيار صاحب المشروع، لم يُربط مزوّد خارجي ولم تُرسل صور أو نصوص أو ملفات صوتية إلى أي خدمة. لا تدّعي هذه المرحلة تشغيل نموذج رؤية عام أو نموذج تفريغ صوتي فعلي.

التحقق النهائي: نجحت المجموعة الكاملة المكونة من 79 اختبارًا دون إخفاقات أو تجاوزات، بما فيها اختبارات كاشف النار والمسار القديم بالأوزان الفعلية. استغرق التشغيل نحو 60 ثانية؛ التقرير محفوظ في tests/reports/integration.json. اختبارات المزوّدين الجدد بقيت محلية ببدائل مصطنعة.

## Prompt 07 — General Vision Classification

GeneralVisionAnalyzer في vision/general.py يقبل ImageRequest وبيانات الصورة، ويفحص الجودة ويصحح الاتجاه. عند توفير VisionProvider، يرسل إليه عبر واجهة Python صورة RGB مصححة بصيغة PNG دون بيانات EXIF أو مسار محلي. تنفيذ المزوّد نفسه غير موجود حاليًا؛ لذا لا يحدث اتصال خارجي.

المؤشرات المدعومة: حشد كثيف، ممر معاق، شخص على الأرض، ضرر مرئي بأصل، وخطر مرئي آخر. تُحوَّل إلى CROWD أو MEDICAL أو TECHNICAL_FAILURE أو OTHER. الضرر بأصل دون assetId موثوق يرجع OTHER للمراجعة، ولا يتحول إلى تشخيص عطل بأصل مجهول. لا تُختلق صناديق للرؤية العامة، وتبقى bbox=null.

كاشف الحريق المتخصص يبقى مصدر مؤشرات النار والدخان، وتُضم نتائجه إلى نفس النتيجة الموحدة. لا تُستخدم الرؤية العامة بديلًا له. إذا فشل أحد المكوّنين لا تُعرض نتيجة جزئية كتحليل كامل. عند غياب مزوّد الرؤية ترجع PROVIDER_NOT_CONFIGURED؛ يبقى مسار ai.inference.analyze_image القديم متاحًا لكشف النار وحدها.

تعليمات المزوّد تفصل الأدلة المرئية عن التشخيص وتمنع استنتاج هوية أو نية إجرامية أو سعة الموقع أو تعطل جهاز من شاشة سوداء/باب مغلق، وتتجاهل التعليمات داخل الصور. هذه تعليمات للنموذج والتحقق البنيوي لا يثبت صحة المحتوى دلاليًا؛ يلزم تقييم فعلي بعد اختيار المزوّد ومراجعة بشرية للنتائج.

## Prompt 08 — Arabic Text Classification

ArabicTextClassifier يعمل محليًا بالقواعد حاليًا ويدعم مؤشرات FIRE وCROWD وMEDICAL وTECHNICAL_FAILURE وOTHER. يستخرج نص الدليل وإزاحته الأصلية، ويدعم بعض صور النفي والتهجئة والتشكيل ويقبل أكثر من فئة في البلاغ.

هذه قواعد أولية وليست نموذج فهم لغوي عام؛ قد تخطئ في اللهجات والنفي المعقد والسخرية والاقتباسات والبلاغات الافتراضية. عدم تطابق الكلمات لا يثبت أن البلاغ آمن. confidence=null لعدم وجود معايرة موثوقة؛ لا تُختلق احتمالات. الفئة MEDICAL تعني مؤشرًا مبلّغًا يحتاج مراجعة وليست تشخيصًا.

مثال تشغيل محلي:

```powershell
.\ai\.venv\Scripts\python.exe -m ai.analyze_report --kind text --request ai/contracts/example-text-request.json
```

المثال يتضمن دخانًا وازدحامًا عند بوابة B1. يظهر B1 في mentionedZone فقط، ويبقى zoneId=null إلى أن تتحقق المنصة منه. zoneId وassetId لا يؤخذان من استنتاج النموذج بل من الطلب الموثوق.

يمكن تمرير TextProvider إلى ArabicTextClassifier(provider=...) لاحقًا. المزوّد يعيد فئة ودليلًا حرفيًا وإزاحاته؛ تُرفض الأدلة غير الموجودة بالنص وأخطاء المخرج بوضوح، ولا يحدث رجوع صامت إلى القواعد عند تعطل المزوّد. نسخة المزوّد هي التي تظهر في modelVersion.

## Prompt 09 — Speech Intelligence

SpeechAnalyzer في audio/speech.py يستقبل AudioRequest والبايتات، ثم يستدعي SpeechProvider.transcribe ويُمرّر النص إلى ArabicTextClassifier نفسه. يمكن حقن مصنف النص المرتبط بمزوّد أيضًا. لا توجد نسخة مستقلة من منطق التصنيف للصوت.

يرجع transcript بالنص واللغة وثقة التفريغ إن كانت متاحة، وإصدارات مكوّن التفريغ والتصنيف. أخطاء التفريغ والمخرج والتصنيف لها رموز مختلفة. الملف الفارغ أو المتجاوز 25 MiB أو التفريغ الفارغ يرجع UNUSABLE، والمزوّد غير المهيأ يرجع ERROR. فحص صلاحية الترميز ومدة الصوت والمهلة الزمنية يقع على تنفيذ المزوّد المستقبلي؛ لا يمكن التحقق من جودة تفريغ حقيقية دون نموذج وعينات موسومة. اللغة الحالية ar؛ اللغات الأخرى ترفض بدل افتراض العربية.

## واجهات الربط دون إرسال بيانات

تعريفات VisionProvider وTextProvider وSpeechProvider في providers/interfaces.py. كل مزوّد يحتاج model_version حقيقيًا ودالة مطابقة للواجهة:

| الواجهة | المدخلات | المخرج المطلوب |
|---|---|---|
| VisionProvider.analyze | image_bytes، instructions، output_schema | VisionResponse |
| TextProvider.classify | text، instructions، output_schema | TextResponse |
| SpeechProvider.transcribe | audio_bytes، mime_type، language | Transcript |

المخرجات كائنات Python قابلة للتحقق، وليست نص Markdown. تنفذ أي إضافة مستقبلية الاتصال والمصادقة والمهل وحدود إعادة المحاولة وتسجيل الأخطاء المنقح. اختيار المزوّد وتكلفته ومكان معالجة البيانات والاختبار الفعلي خطوات لاحقة؛ لا تخزن مفاتيح داخل ملفات المشروع أو البلاغات.

الاستخدام البرمجي بعد توفير كائنات المزوّد الفعلية:

```python
vision = GeneralVisionAnalyzer(provider=vision_provider)
text = ArabicTextClassifier(provider=text_provider)
speech = SpeechAnalyzer(provider=speech_provider, classifier=text)
```

كائنات الاختبار في tests/test_multimodal.py بدائل مصطنعة لا تتصل بالشبكة ولا تمثل جودة أي نموذج حقيقي.

## العقد الموحد والتوافق

UnifiedAnalysis بإصدار schemaVersion=2.0.0 يستخدم الغلاف نفسه للصور والنص والصوت: الهوية والحالة والإصدارات والأدلة والمرشحات والقيود والخطأ. inputType يحدد الهوية المطلوبة، ويمنع اختلاق imageId أو imageQuality للبلاغات النصية والصوتية. الأدلة النصية تحمل textSpan، والبصرية تحمل bbox عندما يتوفر أصلًا. confidence يقبل null للمكوّنات التي لا تعطي درجة موثوقة. جميع المرشحات REVIEW وتتطلب مراجعة بشرية، وseverity=null.

لم تتغير صيغة VisionAnalysis v1 أو صيغة JSONL القديمة. from_fire_analysis يحوّل نتيجة النار القديمة إلى الغلاف الموحد v2 دون فقد الأدلة. يحتاج الخادم إلى اعتماد الإصدار v2 قبل استهلاكه؛ ليس امتدادًا صامتًا متوافقًا مع أي مستهلك v1. ملفات JSON Schema الجديدة موجودة في contracts/ بجانب ملفات v1. validate_unified_for_request يتحقق من تطابق الهوية والموقع والأصل والدليل النصي عند التكامل.

توليد المخططات وإجراء الاختبارات:

```powershell
.\ai\.venv\Scripts\python.exe -m ai.contracts.export_schema
.\ai\.venv\Scripts\python.exe -m ai.run_tests --report ai/tests/reports/fast.json
```

## المتبقي قبل التشغيل الفعلي

1. اختيار مزوّد/نماذج الرؤية واللغة والتفريغ وتنفيذ واجهاتها بمهل وحدود واضحة، عندما يطلب صاحب المشروع تفعيلها.
2. مطابقة عقد v2 مع الخادم، ثم تجربة نقل حقيقية دون إجراءات تشغيلية آلية.
3. تقييم صور حشود وممرات وحالات التباس، وبلاغات عربية ولهجات ونفي معقد، وصوت عربي نظيف ومشوّش، بوسوم بشرية مستقلة.
4. قياس التكلفة والزمن والجودة مع بقاء المراجعة البشرية. لا تعوض هذه الاختبارات اكتمال التقييم المستقل المؤجل لكاشف النار.
